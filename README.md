# Description

A NestJS backend for the Fur'N'Tours website.

# Project setup

```bash
npm install
```

## Compile and run the project

```bash
# development
npm run start

# watch mode
npm run start:dev

# production mode
npm run start:prod
```

## Prisma

```bash
# Create and apply migration from schema
npx prisma migrate dev --name migration_name
```

## Run tests

```bash
# unit tests
npm run test

# e2e tests
npm run test:e2e

# test coverage
npm run test:cov
```
